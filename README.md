</div>

<br/>

<details>
<summary><b>🔮 Adaptive Behavioral Stealth VPN (ABS VPN)</b> — ML-powered traffic obfuscation defeating DPI</summary>

<br/>

> Production VPN service with ML-driven traffic obfuscation that generates unique patterns in real-time, bypassing Deep Packet Inspection of Russian ISPs. Deployed on VPS with a working Telegram bot for config distribution.

<br/>

| Aspect | Details |
|:---|:---|
| **Stack** | `Python` · `scikit-learn` · `FastAPI` · `aiogram 3` · `Go` · `AmneziaWG` · `SQLite` · `Linux` |
| **ML Core** | KDE models (scikit-learn) in FastAPI microservice generate obfuscation parameters in real-time — each connection gets a unique traffic pattern so DPI can't learn the signature |
| **Architecture** | ML API (Python/FastAPI) → Telegram bot (aiogram 3) for config distribution (QR + .conf) → Go proxy for closed-loop ML→transport demo → SQLite storage |
| **Infrastructure** | VPS (Ubuntu): systemd services, ufw firewall, cron auto-cleanup of inactive peers, split-tunnel routing |
| **Result** | AmneziaWG + ML obfuscation passed real DPI (MTS operator) — **10+ MiB lossless**, while Reality (VLESS) and vanilla WireGuard were blocked |
| **Repository** | [![GitHub](https://img.shields.io/badge/View_Repo-7c3aed?style=flat-square&logo=github&logoColor=white&labelColor=0d1117)](https://github.com/levqick/abs-vpn) |

<br/>

Designed and shipped a full-stack ML system end-to-end: from KDE model training and FastAPI serving to Telegram bot UX and production Linux deployment. The ML core continuously adapts obfuscation parameters so each VPN session looks like unique traffic — making signature-based DPI detection infeasible.

</details>

<br/>

<br/>

<details>
<summary><b>🔮 Adaptive Behavioral Stealth VPN (ABS VPN)</b> — ML-powered traffic obfuscation defeating DPI</summary>

<br/>

> Production VPN service with ML-driven traffic obfuscation that generates unique patterns in real-time, bypassing Deep Packet Inspection of Russian ISPs. Deployed on VPS with a working Telegram bot for config distribution.

<br/>

| Aspect | Details |
|:---|:---|
| **Stack** | `Python` · `scikit-learn` · `FastAPI` · `aiogram 3` · `Go` · `AmneziaWG` · `SQLite` · `Linux` |
| **ML Core** | KDE models (scikit-learn) in FastAPI microservice generate obfuscation parameters in real-time — each connection gets a unique traffic pattern so DPI can't learn the signature |
| **Architecture** | ML API (Python/FastAPI) → Telegram bot (aiogram 3) for config distribution (QR + .conf) → Go proxy for closed-loop ML→transport demo → SQLite storage |
| **Infrastructure** | VPS (Ubuntu): systemd services, ufw firewall, cron auto-cleanup of inactive peers, split-tunnel routing |
| **Result** | AmneziaWG + ML obfuscation passed real DPI (MTS operator) — **10+ MiB lossless**, while Reality (VLESS) and vanilla WireGuard were blocked |
| **Repository** | [![GitHub](https://img.shields.io/badge/View_Repo-7c3aed?style=flat-square&logo=github&logoColor=white&labelColor=0d1117)](https://github.com/levqick/abs-vpn) |

<br/>

Designed and shipped a full-stack ML system end-to-end: from KDE model training and FastAPI serving to Telegram bot UX and production Linux deployment. The ML core continuously adapts obfuscation parameters so each VPN session looks like unique traffic — making signature-based DPI detection infeasible.

</details>
